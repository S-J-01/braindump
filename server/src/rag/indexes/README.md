# RAG Vector Search Index

Database: braindump
Collection: embeddedragchunks
Index name: rag_chunks_vector
Index type: Vector Search

## Setup

1. Open MongoDB Atlas
2. Navigate to Search & Vector Search
3. Create a Vector Search index on braindump.embeddedragchunks
4. Select the JSON editor
5. Paste the contents of embeddedRagChunks.vector.json
6. Name the index rag_chunks_vector
7. Wait until the index is ready
